# 问题一建模方案（v2 修订稿）

定位：附件1（100 条原始视频）→ 与附件2 同构的标准化时序特征。P2/P3 复用该坐标系。
原则：与附件2 同构优先；每条规则有附件2 实测行为背书；全部工具/参数可复现。
修订：2026-09-23。依据实测复核修订三处——① text 模态改为 BERT 逐 token 输出（非词级复制）；② 补 T=50 头部截断规则；③ 验证协议删除跨特征集分布对比。新增 wp–word–time 映射层、显式状态 mask、WordPiece 重复加权和失败阈值。

## 1. 数据事实与附件行为分析（已实测）

- 附件2 aligned 3395/728/727；字段 id / raw_text / text_bert(3×50) / text(50×768) / audio(50×74) / vision(50×35) / 双标签；无 NaN/Inf；train/valid/test 整条 vision 全零分别为110/15/28。
- text_bert 行序 = input_ids / attention_mask / token_type_ids；tokenizer = bert-base-uncased（9/9 逐位一致；raw_text→input_ids 抽检 465/465）。
- **text(50×768) = 逐 wordpiece 上下文向量**（疑似 bert-base-uncased last_hidden_state，行范数 12.5±2.5）：同词相邻 subtoken 行 cos≈0.63（bitwise 0/164）、同 token id 样本内重现 cos≈0.45、标点行独立 → **非词级池化复制**；text 的 CLS/SEP 行非零（范数≈12）。
- audio/vision：同词全部 subtoken 行 bitwise 相同（164/164）→ 官方管线为**词级池化后复制**；audio/vision 的 CLS/SEP 行精确全零；非零行不出现在 SEP 之后（0.000%）。
- 按有效语义位置重算，audio 非零率为 train/valid/test = 99.915%/99.732%/100.000%，vision 非零率为94.473%/94.293%/93.925%；vision 零行主要来自无脸或局部不可观测，不能和真实低能量静音混同。
- 标点继承（audio/vision 行级证据）：收尾类 `, . : ; ! ? ' ) %` 继承前词；起始类 `( “ { $ [ #` 继承后词（句中亦然，如 "and ( umm ) but"）；`" - – —` 两可（≈2%）。
- 截断：满 50 样本中 234/253 为头部截断，且 **SEP 恒在最后有效位** → 官方规则 = 保留 CLS+前 48 非特殊片+SEP@49。附件1 有 6 条 clip 非特殊 wordpiece 数 >48。
- 附件1：100 clip；fps 混用（30×83、29.97×10、23.98×5、25×2）；音频 44.1kHz；转写在 label-100.xlsx（text/label/annotation），与附件2 raw_text 18/18 一致（lower/strip）；词数 median 18、max 65（1 条 >50 词）。
- 附件1∩附件2 = 18 条（11 train + 7 test）→ 11 条标定、7 条冻结后独立验证的接口参照系。
- 附件3 aligned 只有 text_bert/audio/vision（文本需自编码）；附件3 unaligned 无 text_bert → **全管线锁 aligned 版本**。

## 2. 统一坐标设计

### 2.1 文本 token 坐标

- 50 步网格由 BERT tokenization 决定：位置 0=[CLS]，1..k=wordpiece，k+1=[SEP]，其余为 padding。50 步是**固定模型索引坐标**，不是等间隔物理时间坐标。
- 定位表述（论文用语）：文本模态天然存在符号位置，不经过物理时间池化；语音和视觉通过物理时间锚映射至该语义索引，实现异构模态统一。
- 一个原词拆成多个 WordPiece 时，音频/视觉向量虽按官方结构复制到各片，但训练池化和位置归因汇总使用 `alpha_i=1/n_wp(word_i)`，避免长词因子片数量更多而被重复加权。

### 2.2 物理时间坐标

- forced alignment 提供**跨模态共享的物理时间参考**（避免"唯一桥梁"式表述）：词区间 I_j=[t_s,t_e)，半开，帧时间戳仅属一词。
- 视觉帧时间 = 帧 pts_time（fps 混用，禁用帧号/fps）；音频 LLD 帧时间 = (k+0.5)×10ms（中心约定）；wav2vec2 对齐输出按 hop 320@16kHz = **20ms 量化**，换算式写入 manifest。
- 词区间合法性：0<t_s<t_e 且时长∈[20ms,3s]，裁剪到 [0, 实测时长]；越界按失败处理。
- 转写规范化：小写、去标点、弯引号→ASCII（wav2vec2 词表外字符触发失败处理）。

### 2.3 wordpiece–word–time 映射层

- 由 tokenizer 的 `word_ids()` 和 `offset_mapping` 构建 wp→原词索引，`##` 仅作一致性校验；不发音 token（标点/括号）不进对齐词序列，按继承规则挂靠邻词，并保留 `attach_type`。
- 输出映射表（每样本）：`position | token_id | token | char_start | char_end | word_id | word_text | wp_count_in_word | alpha | [t_s,t_e] | confidence | attach_type | trunc_flag`。
- 用途：P3 可解释性位置归因 → WordPiece → 原词/原文字符区间 → 真实时间戳的回溯闭环。标点和子词的归因最终聚合到源词。

## 3. 多模态特征生成

### 3.1 text：BERT 逐 token 输出（不参与时间池化）

- H_t = BERT(input_ids, attention_mask) → 50×768；结构 = CLS / wordpiece 隐状态 / SEP / padding。
- 模型 bert-base-uncased（HF，冻结推理，pin revision）；**输出层已标定：last_hidden_state**——2026-09-23 实测 18 条重叠样本逐位 cos=1.0000（AutoModel 标准前向，接口唯一、无搜索过程，标定/验证区分不构成调参风险）；7 条留作 §6.2 对管线端到端输出的正式验证。

### 3.2 audio：区间池化 + 复制（50×25）

- opensmile，eGeMAPSv02 LowLevelDescriptors（25 LLD，10ms 步进，无 delta）。
- P_j = mean{ x_k : t_k ∈ [t_s,t_e) }；词向量 bitwise 复制到该词全部 wp 位；标点按 §2.3 继承表处理。

### 3.3 vision：区间池化 + 复制（50×D_v）

- Py-Feat（备选 OpenFace 2.2），AU+姿态，人脸对齐后提取；帧中心 ∈ [t_s,t_e)。
- 池化/复制规则同 3.2；词区间无检出帧 → 零行。

**维度空间声明（修订 2026-09-24）**：P1 交付原始空间（audio 25 / vision 23）。P2 训练使用附件2 官方特征（audio 74 / vision 35）投影至 64 维模型空间；P1 自产空间仅用于 P1 交付、迁移对照实验与 §6.3 行为级对照，不混入 P2 主实验。两空间不混用，论文统一标注。

## 4. 边界处理

| 场景 | 规则 |
|---|---|
| 非特殊 wordpiece >48 | **头部截断**：保留 CLS+前 48 片+[SEP]@49；整词越界者不入网格，映射表标 trunc；词跨边界者池化向量只复制到保留片 |
| 标点继承 | 收尾类→前词；起始类→后词；两可类（`" - – —`）→默认前词 + flag |
| 词区间无任何有效帧（无帧/未检出脸） | 特征零行，`observed_mask=0`，并记录 `missing_reason`；成功采集到的低能量静音仍是观测值，不视为缺失 |
| 词区间部分帧缺失 | 只对有效帧池化（视觉=人脸检出；语音=逐描述符 nanmean；全 NaN 才零行） |
| 词间静音帧 | 丢弃，不归并 |
| 对齐失败词 | 相邻可信词边界线性插值，映射表打 confidence |
| 失败阈值 | confidence<0.5 逐词记录；单样本失败率>5% 入人工核查清单；>20% 回滚并修订文本规范化后重跑。**修订（2026-09-23 全量审计）**：审计证明 >20% 样本源于数据本身（静音轨 RMS≈0、音画不符 ASR-f1≈0），规范化修订无效；失败二分为管线责任（1.0%，门槛≤2%）与数据责任（17.9%，插值放行+quality 标记+manifest 留痕），不再按回滚处置 |

## 5. 输出 schema（一次定型）

每样本：
- text(50,768) f32 ｜ audio(50,25) f32 ｜ vision(50,D_v) f32
- `attention_mask(50,)`：保留 BERT 接口，CLS..SEP 为 1，padding 为 0
- `content_mask(50,)`：真实语义 WordPiece 为 1；CLS/SEP/padding 为 0
- `special_mask(50,)`、`padding_mask(50,)`：分别标记 CLS/SEP 和 padding
- `observed_mask_text/audio/video(50,)`：各模态是否实际观测到；真实零值不改变该 mask
- `quality_text/audio/video(50,)`：对齐置信度、有效帧比例等质量分数；另存 `missing_reason`（如 `observed/no_face/no_frame/alignment_failed/synthetic_masked`）
- `alpha(50,)`：有效原词的反重复权重，`alpha_i=1/n_i`，n_i = 该词**保留的词片 + 继承标点位**合计（grid.py 实现；每词 alpha 合计恒=1），特殊和 padding 位置为 0
- §2.3 映射表：WordPiece→字符/原词→时间区间→置信度→继承来源→截断标志
- `full_word_map`：未截断的完整原词时间表；模型输入仍严格为50步
- 全局：manifest.csv（100 行）+ train 归一化统计量（供 P2 复现）

归一化：存储层存池化原始值；编码器入口按模态标准化（统计量仅 train），缺失位重置零；BERT 文本不做 z-score；尺度差由投影+LayerNorm 吸收。

## 6. 一致性验证（P1 验收，四指标）

1. **Schema 一致性**：shape/dtype 符合 §5；`content/special/padding` 构成互斥完备分区，`observed_mask` 只在 content 位置生效，SEP 位和截断标志一致。
2. **文本一致性**：11 条重叠样本用于 BERT 输出层、tokenizer 参数和规则标定；冻结后在7条独立重叠样本上一次性验证 H_self vs 附件2 text 逐位 cos。禁止用验证结果反调规则。
3. **Audio/Vision 行为一致性**（不做跨特征集逐维相关）：逐词零行/非零位置一致率、有效词覆盖率（对标上述 train/valid/test 实测率）、缺失比例一致性；辅以逐词能量代理（波形 RMS）与 COVAREP 能量维的逐词相关。
4. **时序回放核对**：覆盖多子词、标点继承、头部截断、混合 fps、无人脸和对齐失败等边界类型（建议8–10条），按映射表把词区间画回波形+帧，人工核验。

### 6.1 机器验收实测回填（2026-09-24）

- **产物契约**：schema `p1.v2`；100 条样本，`error_count=0`；`model_contract` 已记录 BERT revision/权重 SHA、wav2vec2 checkpoint SHA、Py-Feat 四段链与 top-1 策略、openSMILE 配置、设备与视觉 batch size。
- **覆盖完整性**：label-100.xlsx 的 100 个 `(video_id, clip_id)` 与输出 pkl 一一对应；缺失、重复、多余均为 0。
- **Schema**：100/100 个样本通过 `validate_sample`；结构 mask 分区、dtype/shape、SEP 位置、观测 mask 范围和映射表均无违例。原始输出空间为 text `50×768`、audio `50×25`、vision `50×23`。
- **文本留出验证**：附件2 test 重叠的 7 条样本 `text_bert` 逐位相等（7/7），自编码 `text` 的最小位置 cosine 为 `1.000000`。
- **行为一致性**：audio 非零率 `1.00000`，附件2 基准 `0.99915`；vision 非零率 `0.94704`，附件2 基准 `0.94473`；两项均在 `±2` 个百分点容差内。另记录自然观测覆盖率 audio `1.00000`、vision `0.94704`，该覆盖率仅作参考量。
- **对齐质量**：100 条中 alignment status 为 `ok/review/rollback = 43/33/24`；数据异常样本保留输出，并在 `quality`、`missing_reason` 和 manifest 中留痕。
- **可复现校验**：`features.pkl`、`normalization_stats.pkl`、`manifest.csv` 的 SHA-256 已写入 `data_manifest.json` 并复核一致。

以上为机器验收结果；典型样本人工回放（至少覆盖 2 条 rollback 样本及边界类型）完成后，才闭合第 4 项时序回放验收。
