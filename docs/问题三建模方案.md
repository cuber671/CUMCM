# 问题三建模方案（v1.0 Freeze：只允许修公式/改文字/调参数）

框架名：**缺失感知反事实解释框架（Missing-aware Counterfactual Explanation Framework, MCEF）**
定位：P3 不引入额外预测模型（解释对象 = 实际预测器）。MCEF = MRFN 本体 + 归因层 + 保真度验证层 + 证据回溯层。
创新表述（收敛后）：P2 缺失感知训练降低了模态联盟反事实输入与训练分布之间的偏移，为基于联盟干预的 Shapley 解释提供有效性基础；创新在"缺失感知 + 反事实解释"的闭环，不在 Shapley 本身。

## 1. 任务与输出（题目对应）

- 同时输出：极性、强度、主要参考模态、模态作用程度、关键证据定位（可对应文本片段/语音时段/视觉关键帧）。
- 附件4：20 条完整三模态特征 + 原始视频。**视频仅用于证据渲染回看，不重新提特征，接口不破。**

## 2. 可解释目标：四公理

| 公理 | 数学表述 | 保证方式 |
|---|---|---|
| 完备性 | 分类：Σ_m φ_m^c = p_c(x) − p_c(x_∅)；回归：Σ_m φ_m^r = ŷ − ŷ_∅（两输出空间分开表述，不统一写 v） | 精确 Shapley |
| 保真性 | 按归因序删除的预测偏移 ≫ 随机序 | 扰动实验（§5） |
| 一致性 | 归因与门控的信任分配趋势一致 | g–φ 分析（§6） |
| 可回溯性 | 每个 a_{m,j} 映射至具体证据 | P1 对齐表（§7） |

## 3. 模态贡献：精确 Shapley（8 联盟枚举）

- 联盟输入构造（消歧：不是"删除模态"，是掩码置零+缺失编码）：δ_m^S = δ_m if m∈S else 0；v(S) = f(x_t·δ_t^S, x_a·δ_a^S, x_v·δ_v^S)。联盟值：v(S) 经 MRFN 缺失状态编码进入；v(∅) = f(x, δ≡0)（全缺失状态，与 P2 编码一致，**非全零输入**）。
- φ_m = Σ_S [|S|!(2−|S|)!/3!]·[v(S∪{m}) − v(S)]，v 取双值：分类（预测类概率）与回归（强度）。
- **报告带方向**：φ_m^+ / φ_m^- 分列，解释卡以分类为主、回归 φ 作补充：

| 模态 | 贡献 | 方向 |
|---|---|---|
| text | +0.61 | 支持 Positive |
| audio | −0.12 | 抑制 |
| vision | +0.08 | 辅助 |

- 主要参考模态 = argmax|φ_m|；作用程度 = 归一化 |φ|。

## 4. 位置归因：IG 默认，LOO 只做裁判

- **Integrated Gradients（交付方法）**：IG_i = (x_i − x'_i)·∫₀¹ ∂F(x'+α(x−x'))/∂x_i dα；基线 x' = 全缺失状态输入（δ≡0 路径），与 v(∅) 同构；基线组数 32。
- **基线敏感性消融（防"解释依赖人为基线"质疑）**：全缺失基线 vs 零向量基线 vs 均值基线，报告三者解释排序的 Spearman 相关。
- **LOO deletion（验证方法）**：每样本 50×3 次前向，仅用于 fidelity 裁判与消融，不全量生成解释。
- Attention rollout：仅作模型内部信息流分析，**不作为最终解释输出**。
- 纪律：不引入 LIME / KernelSHAP / GradCAM / DeepLIFT / Occlusion——一个主解释体系 + 一个验证体系。

## 5. 保真度与稳定性验证

1. 删除/插入曲线：按 a 降序用 **P2 抹除算子**逐比例置缺失（复用算子），对照随机序，报 AOPC；
2. Comprehensiveness / Sufficiency（ERASER 口径）；
3. 随机化检验：权重随机化后归因坍缩，排除输入伪解释；
4. **解释稳定性**：轻扰动 x′ 下 sim(E(x), E(x′))，Spearman 秩相关（缺失场景下解释可信的重要维度）；
5. IG↔LOO 排序一致性：交叉验证归因可信度；
6. **证据导向缺失测试（案例级验证，不作为新指标）**：依解释取 TOP-k 证据位置删除 vs 随机删除，逐典型样本对比预测翻转——直接呼应题目"找关键证据"。

## 6. 门控–归因一致性分析（g–φ）

定位：**分析模型信任机制（g）与实际贡献（φ）的一致性**，非验证等同——门控是融合权重、Shapley 是预测贡献，二者含义不同。
输出：valid 上 per-modality 散点 + 趋势结论，**Pearson 与 Spearman 双报告**（门控与 Shapley 未必线性相关）；与 P2 §8.4 的 g–I 分析互证。

## 7. 证据回溯：P1 对齐表变现

**归因粒度声明**：位置 j=1..50 在三模态上同义——text=wordpiece 位置，audio/vision=词级池化位置（P1 已折叠）。**位置归因继承 P1 建立的统一语义时间坐标**，这是 P1→P3 的实质性连接（vision 并非原始 50 帧）。

链路：a_{m,j}（wordpiece）→ 词 → [t_s, t_e] → 证据渲染。
语义描述**到特征组级别**，不强行解释单维（输入是 LLD，解释就不能谎称"F0 某一维"）：

| 模态 | 证据形态 | 语义字典 |
|---|---|---|
| text | 词片段（tokenizer decode） | 原句高亮 |
| audio | 时间区间 | LLD 分组：pitch-related / energy-related / spectral-related，报组的归因和与走势 |
| vision | 帧号（区间内归因最大帧） | AU6/AU12 **等面部动作单元对应的表情线索**（AU 解释具有情境依赖，不写"=微笑"）+ Py-Feat 表情假设 |

**解释卡模板**：

```
样本01 | 极性 Positive(P=0.87) | 强度 +1.42
主要模态: text (φ: t=+0.61, a=−0.12, v=+0.08)
证据TOP3:
 [text] "I absolutely love this thing" t∈[2.1,4.3]s a=0.83
 [audio] pitch 组上升段 t∈[4.3,5.0]s a=0.41
 [vision] 帧#87(t=2.9s) AU6+AU12(微笑) a=0.22
```

## 8. 交付

- 附件4 CSV 双文件：
  - prediction: sample_id, pred_polarity, pred_intensity, confidence(分类最大概率), main_modality, phi_t, phi_a, phi_v（带符号）
  - evidence 长表: sample_id, modality, evidence_type, content, t_start, t_end, attribution, rank(TOP1/2/3)
- 论文图表：解释卡 ≥3 个典型样本、φ 方向表、删除/插入曲线、稳定性结果、g–φ 散点、位置归因分布图、附件4 全量汇总表。
- 论文表述纪律：不写"合法化"，写"降低分布偏移、提供有效性基础"；创新点落"缺失感知+反事实解释闭环"。

## 9. 风险与边界

- v(S) 的有效性依赖 P2 训练分布覆盖全部联盟——分量 A/B/C 已覆盖；论文如实说明依赖关系。
- IG 基线为全缺失状态：消融中与零基线对比，防"基线选择决定解释"质疑。
- 附件4 无标签：行为分析与解释展示，不做精度声明。
