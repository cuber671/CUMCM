## M2 Shapley 联盟层（2026-09-25，已验收 ALL PASS）

产物：`src/p3/shapley.py`（联盟构造+精确 Shapley+完备性）、

`runs/p3/m2/shapley_att4.json`（20 条缓存：8 联盟值/双输出 φ/门控/指纹，M3/M4 复用）。

### 实施要点（与预注册逐条对应）

- **8 联盟固定顺序**（∅, t, a, v, ta, tv, av, tav，冻结为缓存键序）；
- **text∉S 时 [MASK] 前置重编码**（`mask_text_tokens` 越界即拒，CLS/SEP/padding 不动），
  未对完整 embedding 事后置零（单测 Spy 编码器捕获输入实证）；
- **v(∅) 与 P2 Full 缺失同构**：text 全 content 位 [MASK] + 三模态 avail=0，
  结构 mask 全保留（非全零输入，单测 test_empty_coalition 实证）；
- **双输出带符号 φ**：分类为 3 维概率向量（逐类完备）、回归为标量；权重用精确分数
  （1/3, 1/6, 1/3）计算，杜绝权重浮点误差；
- **集成口径** = P2 终评同款：3 seeds 各自微调 BERT 编码 + 概率/回归均值。

### 验收结果（4/4 ALL PASS）

1. coalition_enumeration：20 条 × 恰好 8 联盟、键序一致 ✅
2. completeness_all：**20/20 分类逐类 + 回归 Σφ = v(N) − v(∅)**，最大残差 3.0e-8（容差 1e-5）✅
3. dummy_player_13：#13（vision 整模态自然缺失）φ_v^cls ≡ [0,0,0]、φ_v^r ≡ 0——
   哑玩家公理的真实数据实证，已单独标记 ✅
4. anchor_sanity_internal：5 条附件2 重合样本预测 vs 真实标签 **5/5 一致**
   （仅内部 sanity，不入解释输出与精度声明）✅

### 首批行为观察（供 M6 解释卡选样）

- 主导模态（argmax|φ_pred 类|）：**text 18 / vision 2 / audio 0**——文本主导与 P2 结论一致；
  两个 vision 主导样本（#13 为哑玩家除外的弱文本样本）值得进解释卡；
- 高置信样本（#09/#16/#17，conf>0.98）呈现大 φ_text（0.55–0.68）+ 小 φ_av，
  即"文本单模态几乎解释全部预测偏移"；
- 方向性可读：如 #04（pred=neg）φ_text=[+0.36, −0.08, −0.28]——文本同时支持负类、
  抑制正类，解释卡可直呈双向作用。
