### 可微输入层级（显式声明）

- **text：BERT 输出嵌入层** last_hidden_state (50,768)——冻结编码器（各 seed 自己的微调
  BERT），α 路径 E(α)=E′+α(E−E′) 作用在连续嵌入空间，**绝不对离散 token ID 数值插值**；
- **audio/vision：z-score 标准化连续特征** (50,74)/(50,35)。

### 第二轮审阅修正（四项，全部落实）

1. **基线语义重定义（高优先级）**：第一轮声称 missing 基线"与 v(∅) 同构"不实——
   v(∅) 是 avail=0 的联盟级反事实，而 IG 路径必须 avail=o（探针实测：avail=0 时
   ∂F/∂x≡0，#01/#13/#18 IG 全零 0.00e+00，博弈退化为 v≡v(∅) 平凡博弈/全哑玩家）。
   修正后口径：**基线 = 全缺失特征值（text 全 [MASK] 嵌入、a/v 缺失行），avail 固定
   自然观测 o，语义 = "给定观测状态下的特征值贡献"（条件特征归因）**；v(∅) 仅作
   Shapley 参照，两层参照系不同属设计选择。方案 §4 已同步改文字。
2. **积分误差逐样本验收（高优先级）**：第一轮用全体最大 gap / 全体最大 ΔF 掩盖了
   6 个逐样本超限（#03 reg 6.5%、#06 reg 5.3%、#08 reg 5.6%、#13 reg 11.1%、
   #18 cls 5.3%、#18 reg 6.3%）。修正：右端点 → **中点求积**、32 → **64 步**
   （右端点 O(1/n) 收敛过慢；中点 32 已修复 5/6，64 留裕量），验收改逐样本逐输出。
3. **alpha 角色明确（中优先级）**：第一轮只用 tokenizer word_ids。修正：改用
   **P1 `build_grid` 的 `wp_word_map` + `alpha`**（实测与附件4 存储网格
   **20/20 逐 token 对齐**，含 #07/#18 截断样本）。**措辞统一（第三轮审计）**：
   alpha 确定词归属、片数与截断覆盖并断言词内均匀（α_j=1/n_w）；词级**数值聚合 =
   质量守恒求和** A_w = Σ_{j∈w} a_j——α_j 数值不进入 A_w（均匀划分下与 α 取值
   无关），保证 Σ_w A_w = Σ_j a_j。单测：五子词样本 unbelievably 期望 = 求和而非均值。
4. **结构位零归因改为断言（中优先级，第三轮审计升级为逐 seed）**：第一轮只检查
   uncovered≥0。修正：**全基线 × 双输出 × 三模态 × 20 样本 × 逐 seed**（非均值后），
   IG 在不可用位（非 content ∪ content∧o=0）最大绝对值 ≤ 1e-6——实测 **0.0
   （逐位精确零，架构级）**；#13 作为全模态自然实例单列复检。

| 基线 | text | audio/vision |

### F 失败的结构性诊断（diag_p3_m4_loo.py，全 20 条）

- **确定性排除**：同输入重复 LOO 逐位差 = 0.0（非数值噪声）；
- **符号约定排除**：ρ(|IG|,\|Δp\|) 与符号版均低，|Δp| 修复无效；
- **局部性决定一致性**：局部干预（a/v 仅翻 avail 位）下 IG↔LOO **强一致**
  （audio ρ_abs=0.739、vision 0.732，top-20% 重合 76%/71%）；
  text 的 [MASK] 重编码是**非局部干预**（BERT 从上下文推断被掩 token，
  可推断词删除后 Δp 小）→ 与嵌入层局部 IG 属**不同反事实**
  （删除排序≈上下文可推断性，IG≈嵌入敏感度），text ρ_abs=0.213、头部重合 29%；
- **全局忠实性仍在**：累积删除/插入曲线（A/B/C）以 \|IG\| 序显著胜随机
  （19/20 逐样本胜；#19 为唯一例外，AOPC −0.082）。

**结论**：保真度由 A–E 五项确立；IG↔LOO 对 text 报告为有限一致并给出机制解释
（a/v 对照证明 IG 本身局部忠实；差异源于 BERT 掩码推断的干预语义）。
论文如实双报告，不宣称 6/6。

### 方法边界（论文表述纪律，2026-09-25 第四轮审阅）

- IG 的参照系 = **固定自然观测 avail=o 的条件特征归因**（嵌入层）；删除/插入验证
  用的是 **P2 抹除算子**（text = [MASK]+avail 清位，a/v = avail 清位）。
  因此 **A/B/C 证明的是"按 IG 排序选出的证据，在实际 P2 缺失干预下具有较好的
  操作性保真度"**，不是"IG 与 LOO 共用同一反事实的同路径积分验证"。
- 论文表述模板：**"全局删除/插入保真度通过；单点 text LOO 与嵌入级 IG 存在
  干预语义差异（[MASK] 重编码非局部），audio/vision 局部干预下 IG–LOO 一致性较高"**。
  禁止写"IG 已通过单点 LOO 裁判"；M6 解释卡可引用 A/B/C 全局保真度。

### 实施要点

- 抹除算子 = P2 语义位置级：text 删除 = [MASK] 前置 + avail 清位（P2 make_batch_avail
  同款），a/v = avail 清位（值保留）；结构与 padding 永不触碰（越界即拒）；
- 全局证据序 = 三模态可用位按 |IG_cls|（M3 主基线）跨模态合并降序；
  随机对照 5 组种子化（[2026, n, rep, f×100]）；插入起点 = 全删除态；
- 稳定性加噪仅可用位（ε~N(0, 0.05σ_m)，按可用位数值 std 定标），基线不扰；
- 随机化 = MRFN 头重初始化（seed 999，BERT 固定），目标类取随机模型自身 argmax；
- #13 vision（零可用位）全流程防崩溃守卫（n=0 → nan 跳过）。

## M5 g–φ 一致性（2026-09-25，ALL PASS）

|---|---|---|---|---|
