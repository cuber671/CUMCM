# 问题二建模方案（v2.0 Freeze：只允许修公式/改文字/调参数，不再加模块换架构）

定位：模态局部缺失下的鲁棒情感预测。核心模型：**缺失感知可靠融合网络（Missing-aware Reliability Fusion Network, MRFN）**。
创新边界（论文表述）：占位嵌入、掩码注意力、门控融合均为经典机制；本文贡献是面向"局部连续缺失"的**信息可用性形式化**与三者的闭环组合——缺失状态成为显式输入变量、信息传播受可用性约束、跨模态信任随可靠性重分配。
输入：问题一 schema（50 网格 + α/δ）。实验仅用附件2 train/valid；test 终跑一次；附件3 只推理。

## 1. 数据版图（已锁定，实测证据见问题一/讨论记录）

- 锁 aligned；train 3395 / valid 728 / test 727；文本用自有 frozen bert-base-uncased 从 text_bert 统一编码（与附件3 同接口）。
- 附件3：30 条无标签，仅 4/30 可映射回附件2 test（已验证抹零派生）→ 标签路线关闭，只交付预测+缺失统计分析。
- 附件4 归问题3。unaligned 弃用。题目定义含**文本缺失** → 训练必须覆盖。

## 2. 任务与三级指标体系

- 双头：三分类极性 + 连续强度 [-3,3]。
- **L1 预测性能**：Acc、macro-F1（主报）、weighted-F1（附）、MAE、Pearson。
- **L2 鲁棒性**：性能下降率 D(r) = (S_clean − S_r)/S_clean，按各指标分别计算（macro-F1 与 Pearson 的 D 为主），S 为综合选型分。
- **L3 稳定性**：3 种子间 σ(S) 及各指标 std。

## 3. 缺失空间定义 (M, P, R, L)

- M ⊆ {t,a,v}, M≠∅（7 种组合）
- P：缺失段位置 ∈ {头, 中, 尾, 随机}
- R：缺失率 r = |S| / w（w=有效词位数）
- L：连续性尺度，平均缺失段长 l = (1/N_s)·Σ|s_k|；l 区分"短散段"（附件3 式，l̄≤4）与"连续块"（l̄≥5）

抹除算子：x[S]=0, δ[S]=0；CLS/SEP/填充不抹；除极端场景外保 ≥1 模态 ≥20% 观测。

## 4. 缺失机制分类（理论化）

| 机制 | 定义 | 生成器实现 | 对应训练分量 |
|---|---|---|---|
| MCAR | P(mask\|X)=P(mask)：均匀随机位/段 | 均匀采样 | B 分量 |
| MAR（代理） | 基于观测特征相关性的内容依赖缺失代理机制：低能量/低方差区域优先 | 行范数/局部方差作采样权重，低信号区优先成段 | 新增 E 分量 |

> 论文表述：由于缺少真实采集过程中的缺失原因标签，本文不试图恢复真实缺失机制，而构造可控代理机制用于鲁棒性评价。
| Block | 强制连续长段 | 单块 L~U(5, 0.6w) | B/C 分量 |
| 共缺失 | 多模态同位置联合缺失 | a+v 同步抹除，段长~P{1,2,3,4}=附件3 经验分布 | A 分量 |

训练混合（每 epoch 在线生成）：A 35% / B(MCAR+Block) 40% / C 整模态 15% / D 干净 10%；E(MAR) 10%（A/B/C 权重相应调整为 30/35/15/10/10）。课程调度（前 5 epoch 0→目标）入消融。
评测掩码库：固定种子预生成，全模型共享同一实例。

## 5. Baseline 体系（每一级回答一个问题）

| 级 | 结构 | 回答 |
|---|---|---|
| B0 | 掩码池化 → concat → MLP | 无结构地板 |
| B1 | 各模态独立编码+池化 → concat → MLP（Late Fusion） | 增益来自独立模态编码？ |
| B2 | B1 模态内换双向 GRU（时序） | 增益来自时序？ |

## 6. MRFN 三个核心组件

### 6.1 显式缺失状态编码
z_i^(m) = x_i^(m)·δ_i^(m) + (p_i + e^(m))·(1−δ_i^(m))，e^(m) 可学习占位向量，p_i 位置编码。
**"未观测"作为输入变量，非零填充。** GRU 等价实现：缺失位跳过状态更新、仅推进时间。

### 6.2 可用性约束跨模态交互
Attention(Q=X^(m1), K=X^(m2), V=X^(m2)) 的注意力矩阵施加 M_ij = δ_j^(m2)：
**不可用位置物理上不可参与信息传播**。6 方向 {t↔a, t↔v, a↔v}，d=64, h=2。

### 6.3 可靠性动态融合（门控）
c_m = Σαδ/Σα（覆盖率，硬证据）；q_m = MLP(h_pooled)∈(0,1)（内容质量，软证据）；u_m = 异方差 σ（默认关）。
g = softmax_m(MLP([h_t;h_a;h_v;c_t;c_a;c_v]))，融合表示 h = Σ g_m·h̃(m)。**权重逐样本变化，回答"缺一个模态时信任如何重分配"。**

### 6.4 潜空间一致性约束（辅助，默认关）
不重构信号、只约束语义一致：训练时对完整输入计算 h^(m)（教师侧，仅训练辅助、推理时不需要），对同样本缺失输入经 Dec([h^(m1);h^(m2)]) 得 ĥ^(m)，L_align = ‖h^(m) − ĥ^(m)‖（权重 0.1）。目的：缺失条件下语义空间与完整条件一致，非信号恢复；推理时永不覆盖已观测表示。

## 7. 多任务优化

L = CE_weighted + λ·L1 + 0.1·L_align（若启用）；类别权重 {0:1.17, 1:1.49, 2:0.68}；focal/L1vsMSE 入消融。
AdamW lr 1e-3、wd 1e-4、batch 32、≤40 epoch、早停 patience 8、dropout 0.3、clip 1.0、种子 {1,2,3}。

## 8. 鲁棒评测

### 8.1 选型（只用 valid）
S = ½(Acc+macroF1)/2 + ½[(1−MAE/3)+(Pearson+1)/2]/2；鲁棒项 = 固定掩码库（5 档率×3 模态）上 S 均值；clean:robust = 5:5。

### 8.2 评测网格（固定掩码库）
主线 {t},{a},{v}×率{10,20,40,60,80}%×随机位（15×3 种子）；组合 {ta,tv,av}@40%（3）；位置 {头,中,尾}@40%×{a,v}（6）；极端 7 留模态组合；机制对比 MCAR/MAR/Block/共缺失 @40%（4）。

### 8.3 关键实验：clean→missing 迁移（2×2）
| 训练\测试 | clean | missing |
|---|---|---|
| clean 训练 | ✓ | ✓ |
| 缺失增强训练 | ✓ | ✓ |

证明缺失训练增益来源：右上格差 = 鲁棒性增益，左下格差 = 干净性能代价（期望≈0）。

### 8.4 门控有效性验证（机制不是装饰）
1. g–缺失率响应：audio 缺失率↑ → g_a 是否单调↓（曲线入文）。
2. g–贡献趋势一致性：valid 上 leave-one-out 重要性 I_m = F1_all − F1_−m，考察 I_m↑ 对应 g_m↑ 的**趋势一致性**（门控权重不是贡献度本身，不苛求数值相关=1），论文表述"显著正相关趋势"。

### 8.5 同掩码库对比基线
B3-naive（零填充、无掩码输入、无缺失训练）、均值填充、前向填充、MRFN 全家。

## 9. 消融矩阵

缺失模拟±；缺失状态编码±（退化为零填充）；δ 屏蔽±；门控±（退化为等权）；潜空间一致性±；GRU vs Transformer；L1 vs MSE；weighted CE vs focal；混合权重（含/不含 MAR）；课程调度±；文本接口（附件2 text vs 自编码）。

## 10. 附件3：无标签测试样本上的模型行为分析

（定位：行为分析，非性能验证——无标签不评价准确率。）

- 预测 CSV：sample_id, pred_polarity, pred_intensity, miss_rate_a, miss_rate_v, mean_seg_len_a/v。
- 分析表：30 行逐样本缺失统计+预测；困难样本刻画（高缺失率 × 文本预测不确定度大的样本）；MRFN vs text-only 基线的分歧样本分析（a/v 高缺失时两者应趋同——作为门控行为的旁证）。

## 11. 风险与边界

- 官方集分布窄（a/v 联合缺失、无 text 缺失）：A 分量保贴合，机制结论以合成线为准，两类结论分开表述。
- 选型不碰 test；test 只跑一次。
- 8GB 显存：d=64 轻量骨干，单模型分钟级，全网格可承受。
