# 问题二建模方案（v2.2 Data-grounded Interface Freeze：只允许修公式/改文字/调参数，不再加模块换架构）

接口修订：2026-09-23。依据附件2/3实测数据同步问题一冻结 schema，明确结构 mask、自然观测、合成缺失、质量分数和真实零值的边界；不改变 MRFN 总体架构。

定位：模态局部缺失下的鲁棒情感预测。核心模型：**缺失感知可靠融合网络（Missing-aware Reliability Fusion Network, MRFN）**。
创新边界（论文表述）：占位嵌入、掩码注意力、门控融合均为经典机制；本文贡献是面向"局部连续缺失"的**信息可用性形式化**与三者的闭环组合——缺失状态成为显式输入变量、信息传播受可用性约束、跨模态信任随可靠性重分配。
输入：问题一冻结 schema（50 个模型索引 + `content/special/padding` + 各模态自然观测/质量状态）。`alpha` 仅为 P1/P3 的原词归因辅助字段，不作为附件2训练或 Q2 覆盖率计算的必要输入。实验仅用附件2 train/valid；test 终跑一次；附件3 只推理。

## 1. 数据版图（已锁定，实测证据见问题一/讨论记录）

- 锁 aligned；train 3395 / valid 728 / test 727；文本用自有 frozen bert-base-uncased 从 text_bert 统一编码（与附件3 同接口）。
- 附件3：30 条无标签，仅 4/30 可映射回附件2 test（已验证抹零派生）→ 标签路线关闭，只交付预测+缺失统计分析。
- 附件4 归问题3。unaligned 弃用。题目定义含**文本缺失** → 训练必须覆盖。
- 附件2 实测：有效 WordPiece 数均值为 train/valid/test = 22.65/23.59/23.18，最大均为48；text_bert 中没有真实内容缺失，文本缺失只能通过合成实验构造。
- 附件2 内容位置零行率：audio = 0.085%/0.268%/0%，vision = 5.53%/5.71%/6.08%（train/valid/test）；整条 vision 全零样本为110/15/28。零值不能直接等同于缺失。
- 附件3 对齐版本实测 30 条样本共有605个有效语义位置，audio/vision 同步零行131个（21.65%），27/30条存在局部联合缺失，单样本缺失率最高50%；该现象作为经验性联合抹除模式，不据此宣称 MAR。
- 附件3 对齐样本的 `text_bert` 实际 dtype 为 float32，而附件2为 int64；送入 tokenizer/BERT 前统一转换为整型 token id，不能把 float32 数值当作文本特征直接置零。

## 2. 任务与三级指标体系

- 双头：三分类极性 + 连续强度 [-3,3]。
- **L1 预测性能**：Acc、macro-F1（主报）、weighted-F1（附）、MAE、Pearson。
- **L2 鲁棒性**：先将指标转为越大越好的 utility，再计算下降率。对任一指标 `U`：`D_U(r)=(U_clean-U_r)/max(U_clean,ε)`，同时报告绝对差 `U_clean-U_r`；D 可为负，表示缺失条件下反而提升。
- **L3 稳定性**：3 种子间 σ(S) 及各指标 std。

utility 定义：Acc、macro-F1、weighted-F1 直接作为 utility；`U_MAE=clip(1-MAE/6,0,1)`；`U_Pearson=(Pearson+1)/2`。综合选型分为 `S=0.5·U_cls+0.5·U_reg`，其中 `U_cls=(Acc+macroF1)/2`，`U_reg=(U_MAE+U_Pearson)/2`。

## 3. 缺失空间定义 (M, P, R, L)

- M ⊆ {t,a,v}, M≠∅（7 种组合）
- P：缺失段位置 ∈ {头, 中, 尾, 随机}
- R：缺失率 r = |S| / w（w=有效词位数）
- L：连续性尺度，平均缺失段长 l = (1/N_s)·Σ|s_k|；l 区分"短散段"（附件3 式，l̄≤4）与"连续块"（l̄≥5）

定义 `s_i` 为语义位置 mask，`o_i^(m)` 为自然观测 mask（1=该模态原本观测到），`b_i^(m)` 为合成缺失指示（1=实验抹除），最终可用状态为 `a_i^(m)=o_i^(m)·(1-b_i^(m))`。CLS/SEP/padding 不抹，真实零值不改变 `o`；自然缺失和合成缺失在日志中分开统计。除极端场景外保 ≥1 模态 ≥20% 观测。

对 audio/vision，合成缺失位置执行 `x[S]=0` 并令 `b[S]=1`。对 text，**必须在 BERT 编码前**将被抹除的内容 WordPiece 替换为 `[MASK]`（保留原位置、attention_mask 和50步坐标），再重新编码；禁止先得到完整 `text` 后置零，否则邻近 token 已经吸收了被抹除文本信息。

## 4. 缺失机制分类（理论化）

| 机制 | 定义 | 生成器实现 | 对应训练分量 |
|---|---|---|---|
| MCAR | P(mask\|X)=P(mask)：均匀随机位/段 | 均匀采样 | B 分量 |
| Feature-dependent Missingness Proxy | 基于内容/特征的可控缺失代理：低能量/低方差区域优先；不声称符合 MAR/MNAR 统计定义 | 用抹除前可观测特征的行范数/局部方差作采样权重，低信号区优先成段 | 补充实验 |

> 论文表述：附件3只提供结果特征，不提供缺失原因标签；本文不恢复真实缺失机制，而依据实测联合零行构造经验性缺失模式，并用可控 proxy 补充评价。
| Block | 强制连续长段 | 单块 L~U(5, 0.6w) | B/C 分量 |
| 共缺失 | 多模态同位置联合缺失 | a+v 同步抹除，段长~P{1,2,3,4}=附件3 经验分布 | A 分量 |

训练混合（每 epoch 在线生成）：A（附件3式 audio+vision 联合局部缺失）35% / B（MCAR+Block）40% / C（整模态缺失）15% / D（干净）10%。Feature-dependent proxy 只放入补充实验，避免主结果混合不同缺失机制。
掩码库使用独立 `mask_library_seed` 固定预生成；模型训练只改变 `model_seed`，所有架构和训练策略共享同一掩码实例。

## 6. MRFN 三个核心组件

### 6.1 显式缺失状态编码
令 `δ_i^(m)=a_i^(m)`，仅表示最终该模态是否可用。对内容位置：

`z_i^(m) = p_i + δ_i^(m)·x_i^(m) + (1−δ_i^(m))·e^(m)`，其中 `e^(m)` 为可学习 missing embedding，所有位置统一加入 `p_i`；special/padding 由结构 mask 单独处理。

**“未观测”作为输入变量，非零填充。** `quality` 作为门控的连续证据，不替代 `δ`。GRU 对观测表示和 missing embedding 统一执行正常的时序更新，不再声称“缺失位跳过状态更新”等价于占位嵌入。

### 6.2 可用性约束跨模态交互
Attention(Q=X^(m1), K=X^(m2), V=X^(m2)) 的有效证据 mask 为 `KVM_j = s_j·δ_j^(m2)`，并用 query/content mask 屏蔽 special/padding 输出。缺失位置不能作为证据源，但允许作为 query 从其他已观测位置接受上下文补偿。当 `Σ_j KVM_j=0` 时，该方向跨模态输出直接置零并跳过 softmax，避免全屏蔽导致 NaN。

6 方向为 {t↔a, t↔v, a↔v}，d=64, h=2。

### 6.3 可靠性动态融合（门控）
c_m = Σ_i s_i·δ_i^(m) / Σ_i s_i（覆盖率，硬证据；不依赖附件2不存在的 `alpha`）；q_m = MLP(pool(h_m), pool(quality_m))∈(0,1)（内容质量，软证据）；u_m = 异方差 σ（默认关）。
`g = softmax(MLP([h_t;h_a;h_v;c_t;c_a;c_v;q_t;q_a;q_v]))`，融合表示 `h = Σ g_m·h̃(m)`。**权重逐样本变化，回答“缺一个模态时信任如何重分配”。** `alpha` 只用于 P3 原词归因去重，不进入 Q2 覆盖率定义。

### 6.4 可选训练正则：潜空间一致性（默认关）
不重构信号、只约束语义一致：训练时对完整输入计算 h^(m)（教师侧，仅训练辅助、推理时不需要），对同样本缺失输入经 Dec([h^(m1);h^(m2)]) 得 ĥ^(m)，L_align = ‖h^(m) − ĥ^(m)‖（权重 0.1）。目的：缺失条件下语义空间与完整条件一致，非信号恢复；推理时永不覆盖已观测表示。

## 7. 多任务优化

L = CE_weighted + λ·L1 + 0.1·L_align（仅补充实验启用）；类别权重 {0:1.17, 1:1.49, 2:0.68}；回归输出 `ŷ=3·tanh(r)`，显式限制在 [-3,3]。
AdamW lr 1e-3、wd 1e-4、batch 32、≤40 epoch、早停 patience 8、dropout 0.3、clip 1.0、种子 {1,2,3}。

## 8. 鲁棒评测

### 8.1 选型（只用 valid）
`S=0.5·U_cls+0.5·U_reg`；鲁棒项为固定 mask library 上的 `S` 均值；clean:robust = 5:5。每个原始指标同时报告 utility、绝对差和相对下降率。

### 8.2 评测网格（固定掩码库）
主线 {t},{a},{v}×率{10,20,40,60,80}%×随机位（固定 mask library）；组合 {ta,tv,av}@40%（3）；位置 `{text,audio,vision}×{头,中,尾}@40%`（9）；极端场景至少保留一个模态，三模态全缺失只作边界测试；机制对比 MCAR/Block/附件3式联合缺失 @40%，Feature-dependent proxy 放补充实验。

### 8.3 关键实验：clean→missing 迁移（2×2）
| 训练\测试 | clean | missing |
|---|---|---|
| clean 训练 | ✓ | ✓ |
| 缺失增强训练 | ✓ | ✓ |

证明缺失训练增益来源：右上格差 = 鲁棒性增益，左下格差 = 干净性能代价（期望≈0）。

### 8.4 门控有效性验证（机制不是装饰）
1. g–缺失率响应：audio 缺失率↑ → g_a 是否单调↓（曲线入文）。
2. g–贡献趋势一致性：对 valid 每个样本计算逐样本 leave-one-modality-out 贡献 `I_{i,m}=F_i(x_i)-F_i(x_i\setminus m)`，再与同一样本的 `g_{i,m}` 报 Spearman 相关及置信区间；不再把数据集级 F1 差值与样本级 gate 直接相关。

### 8.5 同掩码库对比基线
B3-naive（零填充、无掩码输入、无缺失训练）、均值填充、前向填充、MRFN 全家。

## 9. 消融矩阵

主消融：Missing Augmentation±、Missing State±、Masked Attention±、Reliability Gate±。架构基线比较与训练策略比较分开，所有架构基线共享同一缺失生成器。GRU/Transformer、focal/MSE、Feature-dependent proxy、课程调度和潜空间一致性列为补充实验。

## 11. 风险与边界

- 官方集文本无真实缺失；附件3主要是 audio/vision 同位置联合零行（实测131/605有效位置，27/30样本），因此文本缺失结论只能来自合成实验，附件3行为结论必须单独表述。
- 选型不碰 test；test 只跑一次。
- 8GB 显存：d=64 轻量骨干，单模型分钟级，全网格可承受。
