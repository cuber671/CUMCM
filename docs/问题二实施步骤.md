## 0. 五项拍板（已定，不再讨论）

1. BERT 冻结为主方案：`eval()+no_grad()`，batch 内在线 `[MASK]` 替换后重新前向；

   附件3 只走推理入口；P1 自产 25/23 维不得混入主实验（仅迁移对照实验可用）。
4. P1 文档维度措辞修正（见 §6）。
5. M1 先交付数据契约 + 缺失生成器，再写 B0。

## 1. 数据契约（M1 验收对象）

### 1.1 输入来源
- 唯一训练/验证来源：附件2 `aligned_50.pkl`，train 3395 / valid 728 / test 727（test 只终跑一次）。
- 标签：classification_labels ∈ {0,1,2}，train 计数 967/758/1670 →
  类权重 {0:1.17, 1:1.49, 2:0.68}（逆频率）；regression_labels ∈ [-3,3]。

### 1.2 自然观测代理（附件2 无显式 mask，必须推导）
```
content_position 且 该模态整行严格 == 0  →  o_m = 0
content_position 其他情况                →  o_m = 1
非 content 位（special/padding）          →  o_m = 0（2026-09-24 审阅拍板，与 P1 统一）
o_text = content_mask（附件2 文本 content 位无真实缺失，不由数值推导）
```
- 已知混淆（留痕）：音频真实静音词在 COVAREP 中可能整行为零，
  该代理会把"观测到的静音"误判为缺失（train 实测 0.085%，影响可忽略，论文脚注交代）。
- **o_m 自带 content 限定**：缺失采样、覆盖率统计、池化一律直接使用 o_m，
  禁止再对 special/padding 位做任何合成抹除（M1-C 单测覆盖）。
- 三态分账保存：`o_m`（自然观测）/ `b_m`（合成抹除）/ `a_m = o_m·(1−b_m)`（最终可用）。

### 1.3 标准化与缺失位语义
- 归一化：按 **clean train** 逐维 z-score 统计量（预注册，只算一次并落盘）；
  统计口径 = content 位且 o_m=1 的位置，float64、ddof=0；
  **std < 1e-8 的常量维以 1.0 替代**（2026-09-24 审阅补充；实测 audio std_min=0.032、
  vision 0.389，当前无常量维，规则为防 NaN 保险）；text 不做 z-score（P1 方案 §5）。
- 不可用位（a=0）的 x **无定义**，模型任何路径不得读取（δ 门控/mask 池化保证）；
  `x[S]=0` 仅为数值占位。**单测**：扰动缺失位的 x 数值，模型输出必须逐位不变。
- **数据事实（2026-09-24 M1-A 实测，全部入报告）**：
  - 附件2 text 的 padding 行是 [PAD] 的 BERT 编码、**100% 非零**（范数≈10.3）
    → "text 行非零"不构成观测证据，任何 text 池化必须 content 掩码；
  - audio/vision 非 content 位（special+padding）严格全零；audio/vision 源 dtype
    float64、text float32、text_bert int64；
  - o_m=0 率（content 位）：audio train 0.0845% / valid 0.2679% / test 0.0000%；
    vision 5.5267% / 5.7070% / 6.0753%；无整样本三模态全缺。

### 1.4 附件3 接口
- `text_bert` 为 float32：转换前断言 `|x - round(x)| < 1e-3` 且值域 ⊆ vocab，
  再转 int64；不得静默截断。
- 只走 `predict_fj3.py` 推理入口，不进训练/验证。

  m1a_state.npz，杜绝"产物来自其他对象却署官方 SHA"。
- 非 content 位 o_m = 0（§1.2 已更新）。
- 新增 pytest.ini（pythonpath=.），裸 `pytest -q` 可复现全绿。
- **二轮残留（同日补完）**：① 缺失 split → KeyError 结构化失败，不再崩溃；

## 2. 掩码库契约
- 路径：`mask_library/<split>/<mechanism>/<modality>/<rate>/<position>/seed<seed>.npz`
- 每文件记录：mask_library_seed、split、样本 id 列表、机制、实际有效缺失率、段长分布。
- 训练/valid/test 的 mask 按样本范围隔离，不共享实例。
- **请求缺失率分母 = o_m=1 的自然可用位**（2026-09-24 拍板）：请求 40% 即从可用位中
  抹除 40%，防止自然缺失较多时实际抹除过少；请求率与实际有效率双双入元数据。
- 每个组合预生成 K=8 个实例；训练时每 step 从库内均匀抽样实例。
- **网格预注册（src/p2/missing.py library_grid，43 组合，顺序冻结=combo_idx）**：
  - mcar × {t,a,v} × {10,20,40,60,80}%（eval_main + train_B）——15
  - mcar × {ta,tv,av} @40%（eval_combo）——3
  - block × {t,a,v} × {头,中,尾} @40%（eval_position）——9
  - joint av × {10,20,40,60}%（train_A；rate40 兼 eval_mech）——4
  - block × {t,a,v} × {20,40,60}% random（train_B；rate40 兼 eval_mech）——9
  - full × {t,a,v} @100%（train_C）——3
  目录名唯一；无三模态全抹组合；训练混合 A/B/C/D 从 tags 取实例（D=clean 不入库）。
- **mask_library_seed=2026**，实例随机源 `default_rng([seed, combo_idx, k])`；
  同 seed 全库逐位可复现（129 文件重生成比对通过），异 seed 不同。
- **joint 段长 pmf（附件3 实测冻结）**：P{1:0.7474, 2:0.1684, 3:0.0421, 4:0.0421}，
  依据 30 文件/605 content 位/131 联合零行/95 段、无 >4 段、平均段长 1.379；
  段限 o_a=o_v=1 的位置、模型索引连续、互不重叠，贪心至目标数。
- 库落盘 `runs/p2/mask_library/`（129 npz ≈11MB）+ library_index.json + acceptance.json
  （2026-09-24 生成：8 检查全过，实际有效率均在请求率容差内）。
- 训练混合比（每 epoch 在线）：A 35% / B 40% / C 15% / D(clean) 10%。

## 3. 模型与训练契约
- B0→MRFN 全阶梯固定：d=64、GRU hidden 64、6 方向注意力 d=64/h=2、
  batch 32、≤40 epoch、早停 patience 8、dropout 0.3、clip 1.0、lr 1e-3、wd 1e-4、
  同一 mask 库、model_seed {1,2,3}。**报告各级参数量**（防容量混淆）。
- B0 掩码池化：排除 special/padding；整段不可用输出零向量（由门控/δ 表达缺失）。
- B3 全屏蔽注意力置零：必须有单测（构造 Σ KVM=0 的批，断言输出无 NaN/Inf 且该方向贡献为 0）。
- λ（L=CE_w+λ·L1）默认 1.0；敏感性 {0.5, 2} 只看 valid，列入补充实验。
- 多数类基线 = 1670/3395 = **49.19%**（B0 验收：clean valid Acc 相对它有提升）。
- 门控单调性为**待验证假设**（H5）：报 Spearman + 分箱均值 + 置信区间，不作硬断言。

## 4. 验收与评测（复用 check 风格，全部落 JSON/CSV）
- L1：Acc / macro-F1（主）/ weighted-F1（附）/ MAE / Pearson。
- L2：utility 变换 + D_U 相对下降率 + 绝对差（D 可为负）。
- L3：3 种子 σ。
- 评测网格、2×2、消融、附件3 行为分析：按方案 §8–§10 执行，test 只终跑一次。

- **M1-E 模型掩码原语（已完成 2026-09-24，待审阅；M1-E 过 = M1 闭合）**：
  src/p2/modules.py 四件——
  ① `masked_pool(h, keep)`：keep 位均值，excluded 位 where 实现（NaN 也不读取），
     全不可用 → 稳定零向量；
  ② `MissingEmbedding`：z = p_i + x_eff + (1−δ)·e^m，x_eff=where(δ=1,x,0)——
     δ·x 的数值安全版（IEEE 0×NaN=NaN，乘法门控挡不住 NaN 占位）；
  ③ `AvailabilityAttention`（d=64/h=2）：KVM_j=s_j·δ_j 屏蔽证据，K 侧 -inf +
     V 侧 where 双防 NaN；ΣKVM=0 的样本行在 wo 后**显式置零**——单测抓到
     "attn=0 但 wo.bias 仍加非零"的实质 bug，正是契约 B3 单测的设计目标；
  ④ `ModalityEncoder`（raw 投影→缺失嵌入，B0/B1+ 复用）+ `count_params`（契约 §3）。
  单测 9 项：numpy 独立参考实现对照、全屏蔽严格零、被屏蔽位 NaN 不传播、
  **§1.3 扰动不变性**（缺失 content/special/padding × 两模态 = 6 区域，有限扰动与
  NaN 注入均逐位不变；a=1 位扰动必须改变输出，防恒等假阳性）、参数量公式核对。
  产物：全库 75 单测绿。
