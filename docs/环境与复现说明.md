# 环境与复现说明（S0 交付物）

状态：**已冻结（2026-09-23 S0 = ALL GREEN）**——四项 smoke 全绿，版本以 environment-manifest.json 为准。

## 三层环境文件

| 层 | 文件 | 用途 |
|---|---|---|
| 运行层 | `.venv/`（不入库） | 实际执行环境 |
| 声明层 | `requirements.in` | 人为指定的直接依赖（19 项），不含传递依赖 |
| 冻结层 | `requirements.lock` | 安装成功后 `uv pip freeze` 导出，唯一复现依据 |
| 描述层 | `environment-manifest.json` | `scripts/check_env.py` 自动生成：版本+GPU+CUDA+模型+特征参数 |

## 锁定顺序（不预先写版本，装完再冻结）

```
Python 3.10 → CUDA/GPU（RTX 5060 Ti 8GB, Blackwell sm_120 → 需 torch cu128）
→ torch/torchaudio（PyPI 默认轮子即 cu128）→ 其余依赖
→ 四项 smoke test → uv pip freeze → requirements.lock
```

## 环境自检（S0 完成判据）

`python scripts/check_env.py`，四项全绿才算 S0 完成：

1. bert-base-uncased tokenizer + forward（last_hidden_state 768 维）
2. wav2vec2 forced_align 机械链路（1s 波形 → 词区间）
3. OpenSMILE eGeMAPSv02 LLD：正弦 wav → 25 维帧级
4. Py-Feat：附件1 真实帧 → 人脸检测 → AU/姿态列

## 特征参数（论文"核心参数"出处 = environment-manifest.json）

- 音频 16 kHz mono；LLD 步进 10 ms
- 视觉帧时间戳 = pts_time（fps 混用，禁用 帧号/fps）
- BERT max_length=50，头部截断（CLS+前 48 非特殊片+SEP@49）
- ffmpeg：imageio-ffmpeg 静态二进制（版本入 manifest）

## 数据接口冻结

每条样本的 manifest 除 id、duration、fps、text_len、wp_len 外，还必须记录 `retained_word_ratio`、`retained_duration_ratio`、各模态观测覆盖率、缺失原因计数和 schema 版本。特征文件必须同时保存 `content/special/padding`、各模态 `observed_mask`、`quality`、`alpha`、映射表及未截断的 `full_word_map`。模型索引固定为50步，真实时间只从原词时间区间读取，不从位置编号或平均 fps 推断。

P1 验证完成后生成并冻结 `data_manifest.json` 和 schema hash；后续 P2/P3 只消费该冻结版本。

## 偏离说明

- 不引入 `ffmpeg-python`（imageio-ffmpeg 二进制直调已覆盖需求）
- ffmpeg 系统包未安装（WSL2 无 sudo），统一用 imageio-ffmpeg 静态二进制
