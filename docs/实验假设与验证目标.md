# 实验假设与验证目标（防"跑完不知道怎么解释"）

## P1 冻结式验证协议

重叠样本只用于接口验证，不用于后续模型选型。11 条样本用于 tokenizer、BERT 输出层、边界规则和特征参数标定；全部规则、版本和阈值冻结后，7 条独立重叠样本只验证一次。时序回放不以随机抽样为主，必须覆盖多子词、标点继承、头部截断、混合 fps、无人脸和对齐失败等边界类型。验证集结果不得反向修改标定规则。

| # | 假设 | 验证实验 | 预期观察 | 判定阈值 / 不成立时的解释预案 |
|---|---|---|---|---|
| H1 | 统一表示可复现附件2 行为 | E1.2/E1.3 | 结构 mask 合法；audio/vision 的观测位置、特殊 token 处理和标点继承行为一致 | 逐项一致率 ≥99%；不达标→检查池化/继承/mask 规则，逐条差异归因 |
| H2 | 文本接口同源 | E1.1 | 11 条标定样本完成接口选择，冻结后7条独立样本 H_self vs 附件2 text 逐位 cos≈1 | cos>0.99 直接用；0.9–0.99→仅在标定集调整；<0.9→全量自编码统一接口 |
| H3 | 强制对齐质量足够 | E1.4/E1.5 | 失败词稀少、边界类型回放核对无误 | 单样本失败率≤5%；>5% 人工核查、>20% 回滚修订规范化；回放边界缺一类则不冻结 |
| H4 | 缺失增强训练提升鲁棒性 | E2.3 迁移 2×2 | augmented 的 utility 下降率 D(r) 小于 clean-trained，且 clean 代价≈0 | 右上格 utility 差>0 且左下格 utility 差≈0 → 成立；clean 代价大→调混合权重 |
| H5 | 门控学到可靠性差异 | E2.4 | g 随对应模态缺失率单调下降；逐样本 g–LOO 贡献 Spearman 为正 | 单调+逐样本趋势一致→成立；不敏感→检查 c/q 输入和 gate 消融 |
| H6 | 阶梯逐级增益可归因 | E2.1/E2.7 | B 级间提升与组件一一对应；去组件则对应机制失效 | 逐级可解释→成立；某级无增益→如实报告并讨论（负结果也是结果） |
| H7 | 缺失感知使联盟归因更可信 | E3.3（MRFN vs 阶梯 B3 对照） | MRFN 的 AOPC / comp-suff 优于无缺失训练对照 | 显著优于→C4 成立；不优于→如实报告，解释定位退回扰动验证 |
| H8 | 位置归因可靠且可回溯 | E3.2/E3.5 | IG↔LOO 秩一致；TOP-k 删除翻转率 ≫ 随机 | Spearman>0.6、TOP-k 翻转显著→成立；低一致→切换 LOO 交付并说明 |
| H9 | 解释稳定 | E3.3 | 轻扰动下 E(x) 的 Spearman 高 | >0.7 稳定；偏低→报告敏感性并给基线消融 |
| H10 | 文本缺失不会泄漏 | E2.2 文本缺失专项 | `[MASK]` 前置重编码模型相对“完整 BERT 后置置零”在缺失位置邻域的表示差异显著，且不使用原缺失 token 语义 | 若仍存在邻域泄漏→检查 token 替换、缓存和重编码链路 |

用法：每完成一个 E，回填本表"实测结果"列；论文第 5–7 章的结论句直接从本表生成，防止结果与叙述脱节。
