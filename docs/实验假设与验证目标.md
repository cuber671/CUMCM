# 实验假设与验证目标（防"跑完不知道怎么解释"）

| # | 假设 | 验证实验 | 预期观察 | 判定阈值 / 不成立时的解释预案 |
|---|---|---|---|---|
| H1 | 统一表示可复现附件2 行为 | E1.2/E1.3 | audio 非零行=非特殊 wp 数、CLS/SEP 零行、标点继承行为一致 | 一致率 ≥99%；不达标→检查池化/继承规则，逐条差异归因 |
| H2 | 文本接口同源 | E1.1 | H_self vs 附件2 text 逐位 cos≈1 | cos>0.99 直接用；0.9–0.99→标定输出层；<0.9→全量自编码统一接口 |
| H3 | 强制对齐质量足够 | E1.4/E1.5 | 失败词稀少、回放核对无误 | 单样本失败率≤5%；>5% 人工核查、>20% 回滚修订规范化 |
| H4 | 缺失增强训练提升鲁棒性 | E2.3 迁移 2×2 | augmented 的 D(r) 显著小于 clean-trained，且 clean 代价≈0 | 右上格差>0 且左下格差≈0 → 成立；clean 代价大→调混合权重/课程调度 |
| H5 | 门控学到可靠性差异 | E2.4 | g 随缺失率单调变化；g–I 正相关趋势 | 单调+趋势一致→成立；不敏感→检查 c 因子是否被 q 因子淹没，报 σ 因子消融 |
| H6 | 阶梯逐级增益可归因 | E2.1/E2.7 | B 级间提升与组件一一对应；去组件则对应机制失效 | 逐级可解释→成立；某级无增益→如实报告并讨论（负结果也是结果） |
| H7 | 缺失感知使联盟归因更可信 | E3.3（MRFN vs 阶梯 B3 对照） | MRFN 的 AOPC / comp-suff 优于无缺失训练对照 | 显著优于→C4 成立；不优于→如实报告，解释定位退回扰动验证 |
| H8 | 位置归因可靠且可回溯 | E3.2/E3.5 | IG↔LOO 秩一致；TOP-k 删除翻转率 ≫ 随机 | Spearman>0.6、TOP-k 翻转显著→成立；低一致→切换 LOO 交付并说明 |
| H9 | 解释稳定 | E3.3 | 轻扰动下 E(x) 的 Spearman 高 | >0.7 稳定；偏低→报告敏感性并给基线消融 |

用法：每完成一个 E，回填本表"实测结果"列；论文第 5–7 章的结论句直接从本表生成，防止结果与叙述脱节。
