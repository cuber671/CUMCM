# 对齐方案

## 当前冻结原则

- 50 步是固定的 WordPiece 模型索引，不等同于等间隔物理时间；音频和视觉通过原词时间区间映射到该索引。
- 统一回溯链为：WordPiece → 字符/原词 → 真实时间；子词归因按 `alpha=1/n_wp` 聚合，截断部分保留在完整词表中但不声称被模型覆盖。
- mask 分为结构状态（content/special/padding）、模态观测状态（observed）、质量分数（quality）和缺失原因；真实零值不自动视为缺失。
- P1 验证采用“11 条标定 → 冻结 → 7 条独立验证 → 边界类型时序回放”协议，验证结果不得反向调参。

## Q2 数据依据

- 附件2 aligned 实际为 train/valid/test = 3395/728/727；文本有效 WordPiece 均值为22.65/23.59/23.18，内容位置没有真实文本缺失。
- 附件2 内容零行率：audio 为0.085%/0.268%/0%，vision 为5.53%/5.71%/6.08%；整条 vision 全零为110/15/28。
- 附件3对齐版本实际605个有效语义位置中有131个 audio/vision同步零行（21.65%），27/30样本出现局部联合缺失；该模式作为经验性联合缺失，不命名为 MAR。
- 文本缺失实验在 BERT 前用 `[MASK]` 替换并重新编码；缺失位置不删除，保持50步坐标。
- 鲁棒性指标先转换为 utility：`U_MAE=clip(1-MAE/6,0,1)`、`U_Pearson=(Pearson+1)/2`，再计算相对下降率。
