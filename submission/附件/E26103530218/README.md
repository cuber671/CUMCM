## 复现方式

进入 `1_可复现核心材料/` 后，按论文附录 A.4 列出的入口脚本顺序执行：

```bash
python scripts/check_env.py
python scripts/run_p1.py
python scripts/check_p1_acceptance.py
# ……详见论文附录 A.4
python scripts/predict_fj3.py    # → 生成 2_专项测试结果/附件3/ 的 CSV
python scripts/predict_fj4.py    # → 生成 2_专项测试结果/附件4/ 的 CSV
```
