# 第二十三届论文格式核对清单（对照 docs/附件2 官方规范）

提交前逐项打勾：

- [ ] 从 A/B/C/D/E/F 六题中确定一题（题目名与摘要页一致）
- [ ] 论文题目、摘要、关键词写在**摘要页**；摘要页下一页起正文
- [ ] 摘要含：建模思路、主要方法、模型、结果与结论、创新点、关键词；**不超过两页**；无需英文摘要
- [ ] 页码从摘要页起 = 1，阿拉伯数字连续编号，**页脚中部**（模板已设；封面显示 0 为官方模板原样）
- [ ] **无页眉**；正文/图表/附录中**无任何身份标志**（校名、姓名、队号只出现在封皮）
- [ ] 题目**三号黑体**；一级标题**四号黑体居中**；其余汉字**小四宋体**、**单倍行距**（cls 已内置）
- [ ] 正文引用处方括号编号 [1][3]；引用书籍注明页码
- [ ] 参考文献按引用次序，格式：
  - 书籍：[编号] 作者，书名，出版地：出版社，起止页码，出版年。
  - 期刊：[编号] 作者，论文名，杂志名，卷期号：起止页码，出版年。
  - 网络：[编号] 作者，资源标题，网址，访问时间（年月日）。
- [ ] 计算结果与源程序按题目要求在规定时间内上传竞赛系统备查
- [ ] 封皮 4 个 logo、表单字段与官方附件3 完全一致（logo 取自官方 .doc 原件）
- [ ] 另按《人工智能工具及输出使用规定》在论文中如实声明 AI 工具使用情况
- [ ] 电子版 PDF 不压缩；MD5 码与 PDF 分窗口按时提交（9/26 12:00 起，见研创网）

## 编译

```bash
make          # xelatex + bibtex + xelatex×2，产出 main.pdf
```

- 必须 **xelatex**（cls 强制 XeTeX；pdflatex 报错）。
- Windows/macOS 下自动使用 华文新魏/隶书（与官方模板逐字一致）；
  Linux/Overleaf（fandol 字体集）以楷体近似替代，正式提交建议在 Windows 环境编译定稿。
- 文件：gmcmthesis.cls（版式）、gmcm.bst（参考文献）、figures/logo1-4（官方原件提取）。

## 常用命令

- `\baominghao{}` 参赛队号、`\schoolname{}` 学校、`\membera/b/c{}` 队员
- `\title{}` 论文题目（摘要页三号黑体）
- `\begin{abstract} ... \keywords{} \end{abstract}` 摘要页
- `\maketoc` 目录（可选，删掉即无目录）
- `Python`/`Matlab` lstlisting 环境、`\appendix` 附录
