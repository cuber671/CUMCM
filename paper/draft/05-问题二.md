# 五 问题二：缺失场景鲁棒预测
- 数据依据：附件2 aligned train/valid/test = 3395/728/727；文本内容无真实缺失，附件3有效语义位置605个，其中131个 audio/vision同步零行（21.65%），27/30样本存在局部联合缺失。
- 主模型 MRFN 由三部分组成：显式 missing embedding、`semantic_mask×availability_mask` 约束的跨模态交互、同时输入覆盖率 c 和质量 q 的可靠性门控；潜空间一致性仅为补充正则。
- 文本缺失在 BERT 前替换为 `[MASK]` 并重新编码，不对完整上下文向量事后置零；音频/视觉合成缺失使用最终可用状态 `a=o(1-b)`。
- 双输出为三分类和 `ŷ=3·tanh(r)` 回归。指标先统一为 utility：`U_MAE=clip(1-MAE/6,0,1)`、`U_Pearson=(Pearson+1)/2`，再计算鲁棒性下降率。
- 实验分为架构基线、训练策略和主消融三层；位置网格覆盖 `{text,audio,vision}×{头,中,尾}`，mask library seed 与 model seed 独立。
