# 二 问题分析与总体技术路线

> 章节定位：承接第一章的三项任务与数据约束，先分析三问的内在耦合与求解难点，再给出各问的技术路线与全篇公共实验纪律；以总体框架图（图1）收束本章，作为后续三～七章的导航图。除特别说明外，本章出现的术语与符号在第三章统一形式化定义。

## 2.1 三问的耦合关系与求解难点

第一章的重述表明，三问分别回应对齐难、缺失难、可追溯难三重挑战，但三者并非三个孤立任务，而是共享同一数据底座的递进链条：问题一自生成的特征文件若被后两问直接采用，则**问题一的统一坐标系同时是问题二的训练接口与问题三的解释接口**。本文正是按这一耦合关系组织全篇：问题一建立以"转写文本 50 个子词位置为主轴、以词级时间区间为回溯链"的统一语义坐标，问题二在该坐标上定义并合成模态缺失，问题三在同一坐标上执行反事实干预并回溯证据。由此，"训练期缺失算子—反事实干预—证据回溯"三者作用于同一语义位置体系，这是本文闭环设计的核心判断。

上述耦合能否成立，取决于三个具体难点能否化解：

1. **异构时序的统一**。附件2 对齐版本三模态共享 50 个序列位置，但原始素材中三模态的采样频率与时间尺度差异显著（文本离散无时长、语音帧率固定、视觉帧率可变），必须回答"50 个位置各自对应原始素材的哪一段物理时间"，对齐才算可核验；
2. **零值语义的消歧**。特征矩阵中的全零既可能是合法观测（如静音、无表情），也可能是信息缺失（附件3 的缺失即以全零连续区间呈现），若不加区分地以零值充当缺失标记，会把真实观测误删为缺失、把缺失误当为观测，因此缺失必须以独立的观测状态显式建模，而非隐含在特征数值中；
3. **无标签测试的可复核性**。附件3、附件4 不提供标签，性能声明无从谈起，交付物只能是"预测结果 + 可独立复核的过程证据"，这要求训练、选型、推理的每一步可追溯。

## 2.2 各问技术路线

针对上述难点与三项任务，本文的技术路线如下。

**问题一：多模态时序对齐模型。** 以转写文本经 WordPiece 子词切分得到的 50 个模型位置为公共主轴建立语义网格；采用开源预训练模型（BERT 语言编码器、wav2vec 2.0 语音编码器）完成基础特征提取，其中词级物理时间由 wav2vec 2.0 的联结主义时序分类（Connectionist Temporal Classification, CTC）强制对齐获得，音频与视觉特征按词时间区间池化后映射至同一网格；对齐失败按"管线责任/数据责任"分层处理而非简单拒收。模型以覆盖完整性、时序可核验性、行为一致性、边界鲁棒性四类机器指标验收，并以典型样本时序回放人工核验。

**问题二：缺失场景下鲁棒情感预测模型。** 以"显式缺失状态编码 + 可用性约束跨模态注意力 + 可靠性门控融合"构建缺失感知可靠融合网络（Missing-aware Reliability Fusion Network, MRFN），缺失以独立状态位显式输入而非零值隐含；架构增益由 B0–B3 阶梯消融逐级定位；鲁棒性在覆盖缺失类型、缺失率、缺失位置与缺失机制的固定场景网格上评测，并以干净—缺失迁移实验分离增益来源；最终在验证集上按预注册准则采纳改进变体 MRFN+（冻结末层微调、多种子集成），在测试集上追加终评。

**问题三：可解释情感预测模型。** 建立缺失感知反事实解释框架，在问题二采纳的预测器上叠加解释层而不引入新预测模型：模态级贡献用三模态联盟的精确 Shapley 值计算（8 个联盟全枚举，满足效率与哑玩家公理），位置级归因用积分梯度（Integrated Gradients, IG）沿可微嵌入路径计算；解释可信性以删除/插入保真度、随机化坍缩、扰动稳定性等操作性检验验证；关键证据沿问题一的映射链回溯到原词与物理时间，对应至文本片段、语音时段或视觉关键帧。

## 2.3 全篇公共实验纪律

为保证三问结果可信、可复核、可复现，全篇执行统一的实验纪律：

1. **数据契约与指纹冻结**。问题一的特征 schema、掩码库、各阶段模型权重与关键产物均以清单文件登记并附 SHA-256 指纹；契约一旦冻结不再回改，后续里程碑只在其上追加，出现偏差即显式声明并重新冻结；
2. **预注册验证**。所有验收门槛在实验运行前冻结，实验后不因结果移动门槛；未通过项保留原始结果并给出诊断，不通过调整口径使其"通过"；
3. **无标签附件的行为分析边界**。附件3、附件4 仅作最终推理，全部产出为预测结果与过程证据，不构成任何精度声明；
4. **单一数据源与同接口约束**。全部建模仅使用题面提供的数据，训练、验证、专项测试保持同一特征版本与同一输入接口。

三问的总体技术路线如图~\ref{fig:g1-framework} 所示：原始视频经三路提取（转写文本、音频流、视频帧）汇聚到问题一的 50 位统一语义网格，同时产出"子词—原词—物理时间"映射表与状态掩码；网格特征连同状态位进入问题二的 MRFN 完成鲁棒预测，其缺失感知训练为问题三的反事实干预提供了分布内保证；问题三的 MCEF 在冻结的预测器上计算模态与位置两级归因，证据经映射表回溯至原始素材。从图中可以看出，三问共用的坐标与状态体系使数据自上而下单向流动、解释自下而上可回溯，构成一个闭环。
