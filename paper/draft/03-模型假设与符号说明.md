# 三 模型假设与符号说明

本章规定后续三问共用的输入、状态和评价口径。H1--H10 是运行前登记的可检验假设，不把假设本身当作实验结论；各假设的支持或不支持在对应问题章中报告。

## 3.1 模型假设

**H1 统一表示可复现附件2行为。** 50 个模型位置采用固定 WordPiece 网格；`content`、`special`、`padding` 构成互斥完备分区，音频和视觉的有效位置、特殊位处理与标点继承规则应与附件2的可观测行为一致。

**H2 文本接口同源。** 文本特征使用与附件2兼容的 BERT `last_hidden_state` 逐 WordPiece 输出。11 条重叠样本用于接口标定，冻结规则后以7条独立重叠样本进行一次性验证，不用验证结果反调参数。

**H3 强制对齐质量可供回溯。** 词区间采用半开区间 $I_j=[t_{s,j},t_{e,j})$；CTC 对齐的 20 ms 量化满足本题的时间定位需要。管线责任错误与数据责任异常分开处理，插值放行必须保留置信度和失败原因。

**H4 缺失增强训练提升鲁棒性。** 在相同模型和掩码库下，包含局部缺失增强的训练相对于仅干净训练，应降低固定缺失场景的 utility 下降率，同时不显著牺牲干净数据性能。

**H5 门控能够反映可用性差异。** 门控权重 $g_m$ 应随对应模态可用性变化；门控与逐样本 leave-one-modality-out 贡献的相关性作为可检验结果，不预设所有模态都必须达到相同强度。

**H6 阶梯增益可归因。** B0、B1、B2、B3 到 MRFN 的结构增量分别对应池化、单模态时序、跨模态交互和缺失感知融合；若某一级没有增益，按负结果报告，不用后验调参解释为有效。

**H7 缺失感知训练为反事实解释提供有效性基础。** MRFN 的训练缺失空间覆盖解释所需的模态联盟，因而联盟干预造成的分布偏移得到降低。该假设由删除/插入及 Comprehensiveness/Sufficiency 等操作性指标检验，不宣称“合法化”反事实输入。

**H8 位置归因可回溯且具有操作性保真度。** 位置归因能够沿 WordPiece—原词—物理时间链路回溯，并在累积删除/插入检验中优于随机顺序。text 的单点 LOO 一致性是单独的诊断项，不预先保证通过。

**H9 解释对轻微扰动稳定。** 对可用连续特征施加小幅扰动后，主要证据位置的排序应保持较高 Spearman 相关；基线敏感性和扰动稳定性分别报告。

**H10 文本缺失不会泄漏。** 文本缺失必须在 BERT 编码前将对应 WordPiece 替换为 `[MASK]` 并重新编码，不能对完整上下文向量事后置零；专项实验检查被抹除 token 的原始语义是否通过邻近表示泄漏。

以上假设均受数据和任务边界约束：附件3、附件4无标签，只进行最终推理和行为/解释展示；附件4的内部重合样本仅作一致性锚点，不用于精度声明。

## 3.2 符号说明

| 符号 | 含义 |
|---|---|
| $m\in\{t,a,v\}$ | 模态索引，分别表示 text、audio、vision |
| $j=0,\ldots,49$ | 固定 50 步模型位置；$j=0$ 为 CLS，末端有效特殊位为 SEP |
| $s_j$ | 语义结构状态，content 位为1，CLS/SEP/padding为0 |
| $x_j^{(m)}$ | 模态 $m$ 在位置 $j$ 的输入特征；不可用位置的数值占位不承担缺失语义 |
| $o_j^{(m)}$ | 自然观测状态，表示原始数据在该 content 位置是否可用 |
| $b_j^{(m)}$ | 合成缺失指示，抹除位置为1 |
| $a_j^{(m)}=o_j^{(m)}(1-b_j^{(m)})$ | 最终可用状态，供模型的缺失编码和可用性注意力使用 |
| $I_j=[t_{s,j},t_{e,j})$ | 原词对应的半开物理时间区间 |
| $H_t$ | BERT 逐 WordPiece 输出的文本上下文矩阵，形状为 $50\times768$ |
| $P_j$ | 音频或视觉在词区间内池化得到并复制到位置 $j$ 的特征 |
| $\alpha_j$ | P1 映射中的词内均匀权，用于位置到原词的归属、片数和截断覆盖判定；词级归因数值采用质量守恒求和 |
| $c_m$、$q_m$ | 模态 $m$ 的覆盖率硬证据和质量软证据 |
| $g_m$ | MRFN 可靠性门控权重，$\sum_m g_m=1$ |
| $N=\{t,a,v\}$ | 三模态全集；$S\subseteq N$ 表示模态联盟 |
| $v(S)$ | 联盟 $S$ 经预测器得到的联盟值；分类和回归输出分开定义 |
| $\varphi_m$ | 模态 $m$ 的精确 Shapley 贡献，带符号 |
| $x'$ | IG 的特征基线；本文固定自然观测状态 $a=o$，不与 $v(\varnothing)$ 混用 |
| $F$、$IG_j$ | 目标输出函数和位置 $j$ 的积分梯度归因 |
| $U_{cls}$、$U_{reg}$ | 分类与回归 utility，分别由 Acc/macro-F1 和 MAE/Pearson 归一化得到 |
| $S$ | 综合 utility，$S=0.5U_{cls}+0.5U_{reg}$；与联盟集合 $S$ 的含义由上下文区分 |
| $D_S(r)$ | 缺失率 $r$ 下综合 utility 的下降率 |
| $S_{select}$ | MRFN+ 的验证集鲁棒选点准则 |
| $T$ | 温度校准参数，附件3/4预测置信度使用 $T=1.2142$ |

其中，Shapley 的联盟级空集值使用 $v(\varnothing)$、`avail=0`；IG 的条件特征基线固定 `avail=o`。两套参照回答不同问题，全文严格分名。
